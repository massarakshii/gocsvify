# gocsvify
Сервис для конвертации файлов Excel (XLS, XLSX, XLSM) и Access (ACCDB, MDB) в CSV. Работает как демон: следит за папкой входящих файлов, конвертирует их пулом воркеров и складывает результат в папку выхода. Дополнительно может поднимать HTTP API для загрузки файлов, проверки статуса и скачивания результата.
